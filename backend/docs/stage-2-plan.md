# Этап 2: авторизация по ТЗ 1.2

Работа ограничена FinanceApp, Docker разрешён. CI и публикация не выполняются.
V1 сохраняется без изменений; существующие сессии прежнего формата отзываются V2.

1. V2: приглашения, устройства, семьи, JWT jti, status, cascade и роль выпуска кодов.
   Проверить чистый старт и upgrade с V1, права runtime и сохранность финансовых строк.
2. Криптография: Argon2id/DelegatingPasswordEncoder, встроенный список паролей,
   CSPRNG, SHA-256, JWT HS256 через Spring Security/Nimbus, ключи из файлов с kid.
3. Транзакции регистрации/login/refresh/logout/delete; PostgreSQL-блокировки
   пользователя перед семьёй. Replay возвращает результат отказа из транзакции,
   а исключение HTTP создаётся после commit, чтобы отзыв не откатывался.
4. API, проверка подписи и живой семьи, безопасные ошибки, rate limiter 5/15 минут
   и общий 60/мин, trusted proxy/Caddy. Отсутствие fallback пользователей/секретов.
5. Локальная команда create-invite с отдельными credentials и TTL, без web context.
6. JUnit 5 + реальный HTTP/PostgreSQL, конкурентные refresh/регистрации, каскад,
   JWT/kid/параметры паролей, spoofed proxy headers; clean check bootJar >=80%.
7. OpenAPI и эксплуатационные инструкции описывают только фактически реализованное.

Этапы domain/sync остаются следующими; неизвестные маршруты закрыты denyAll.
