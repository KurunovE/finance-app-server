# Swagger / OpenAPI

После запуска приложения с профилем `local` откройте:

- Swagger UI: http://localhost:8080/swagger-ui.html
- Контракт: http://localhost:8080/api-docs/openapi.yaml

Если порт изменён, замените 8080. UI использует текущий сервер для Try it out.
В `Authorize` вставьте accessToken из login без префикса Bearer.
Примеры токенов и приглашений в документации демонстрационные: замените их действительными значениями.

Единый источник документации — `docs/openapi.yaml` (JSON, совместимый с YAML).
Gradle копирует его в `static/api-docs` при обработке ресурсов. UI использует этот контракт; автоматически сгенерированная схема `/v3/api-docs` не публикуется.
Описаны все 16 бизнес-операций и проверка `/actuator/health`: параметры, тела, ответы, авторизация, ошибки, примеры и порядок восстановления.

В профиле `prod` и без профиля `local` доступ к документации закрыт. При одновременных `local,prod` доступ также закрыт.
Swagger UI по умолчанию выключен; профиль `local` включает его. Токены между перезагрузками страницы не сохраняются, отправка контракта во внешний валидатор отключена.

Используется springdoc 2.8.17 для Spring Boot 3.5: [совместимость и настройка](https://springdoc.org/v2/), [настройки Swagger UI](https://swagger.io/docs/open-source-tools/swagger-ui/usage/configuration/).
